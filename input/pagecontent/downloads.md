### Downloads

#### npm package

This IG is distributed as an npm package. Install it using the FHIR package registry:

```
npm --registry https://packages.fhir.org install nictiz.fhir.nl.r4.acutezorg
```

Or declare it as a dependency in your `package.json`:

```json
{
  "dependencies": {
    "nictiz.fhir.nl.r4.acutezorg": "0.1.0"
  }
}
```
